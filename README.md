# 📌 Overview

SecureVault is an advanced cybersecurity and secure communication platform designed to demonstrate modern cryptographic systems, AI-powered steganography, blockchain-based logging, and secure communication techniques.

The platform combines multiple layers of security technologies into a unified dashboard with a futuristic cyberpunk-inspired interface.

---

# 🚀 Key Features

## 🔐 AES-256 Encryption System
- Military-grade AES-256-CBC encryption
- Dynamic Initialization Vector (IV)
- QR code generation for encrypted data sharing
- Secure decryption engine

---

## 🖼️ Image Steganography
- LSB (Least Significant Bit) image steganography
- Hide secret messages inside images
- Extract hidden information securely
- PNG/JPEG support

---

## 🤖 AI Advanced Steganography
- DNA-based cryptography
- Audio steganography
- Ultrasonic frequency embedding
- AI-driven security processing

---

## 📋 Blockchain Audit Logging
- SHA-256 chained blockchain logs
- Tamper-proof security event records
- Real-time monitoring system
- User/IP activity tracking

---

## 💬 Secure Real-Time Chat
- Socket.io powered communication
- Encrypted room-based messaging
- Secure message transmission
- Real-time updates

---

## 🔑 Multi-Factor Authentication
- JWT-based authentication
- OTP email verification
- Account lockout mechanism
- Risk scoring system
